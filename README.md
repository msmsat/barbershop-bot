Профессиональная система автоматизации записи для барбершопа, построенная на микросервисной архитектуре. Система состоит из трех взаимосвязанных Telegram-ботов, синхронизированных с Google Calendar и платежными системами.

---

## 🚀 Функционал системы

Проект разделен на три независимых модуля для безопасности и удобства использования:

### 1. 👤 Клиентский Сервис (`ClientToBarber.py`)
* **Умная запись:** Алгоритм поиска свободных слотов с учетом рабочего графика мастеров.
* **Оплата:** * Интеграция с **CryptoPay** (USDT).
    * Поддержка **Telegram Stars**.
    * Оплата картой (заготовка под Portmone).
* **Личный кабинет:** Просмотр активных записей, перенос времени, история посещений.

### 2. ✂️ Сервис Барбера (`BarberToClient.py`)
* **Управление расписанием:** Просмотр записей на день/неделю.
* **Менеджмент выходных:** Возможность закрывать дни для записи через календарь внутри бота.
* **Уведомления:** Мгновенные оповещения о новых записях или отменах.

### 3. ⚙️ Панель Администратора (`AdminBot.py`)
* **Управление персоналом:** Добавление/удаление мастеров.
* **Аналитика:** Детальная статистика по доходам, количеству записей и возвратам.
* **Настройки:** Редактирование прайса и списка услуг без перезагрузки бота.

## 🛠 Технический стек

* **Язык:** Python 3.11
* **Фреймворк:** Aiogram 3.x (асинхронный)
* **База данных:** SQLite + `aiosqlite` (полностью асинхронные запросы)
* **HTTP-клиент:** `aiohttp` (для запросов к CryptoPay API и Google API)
* **Внешние интеграции:** * Google Calendar API (синхронизация событий).
    * CryptoPay API (проверка инвойсов).
